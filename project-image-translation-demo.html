SOP · 小红书 / 图片翻译

图片翻译规则与标注 SOP

OCR 识别出文字之后，按「意图 → 渲染 → 高价值」三步判断哪些文字该翻、哪些不该翻，最后对渲染效果打分。

0流程开始 · OCR 识别出文字

先由 OCR 识别出图片中的所有文字块，然后进入三步判断：意图判断 → 渲染判断 → 是否高价值，最后对渲染效果打分。

整体链路：OCR 识别文字 → 分块判断意图（强 / 弱 / 无）→ 判断是否可渲染 → 判断是否高价值 → 渲染效果打分。

1Step 1 · 意图判断

判断每一块文字是「有意识要传递信息」还是「附带出现的」。弱意图的判断视角：从用户视角判断——是用于传递信息的有意识表达吗？

强意图

  • 标题
  • 介绍 / 文字说明
  • APP 截图

弱意图

  • 物品自带文字：标签、说明书、广告牌、手写笔记等
  • 设备水印

无意图

  • 数字 / 货币 / 商标 / 公章
  • 虚化文字
  • 字素 / 艺术字
  • 个人水印

2Step 2 · 渲染判断

判断文字块在翻译渲染后能否正常呈现，分为「不可渲染」和「渲染效果差」两类。

不可渲染

  • 竖排文字
  • 重叠文字
  • 不连续文字（一字一坑）
  • 虚化字
  • 艺术字

渲染效果差

  • 文字过小
  • 文字过多
  • 排版复杂的人工制图
  • 复杂的 APP 截图
  • 人脸与身体
标注时先排除三大类不可渲染的【文字过多】【排版复杂的人工制图】【复杂的 app 截图】→ 标不可渲染，不需要判断 OCR 框。

3Step 3 · 是否高价值

对不可渲染的图片，进一步判断是否属于高价值内容——高价值则走端侧翻译，否则流程结束。

高价值内容

  • 旅行攻略
  • 产品评测
  • 影视综艺台词截图
  • 娱乐资讯
判断结果：是高价值 → 走端侧翻译；不是 → 流程结束。

4输出 · 渲染效果打分

以上判断完成后，对模型输出渲染后的效果打分：

0
有错误、不合格
1
没有错误但细节不完美、合格
2
各方面细节都很好、优秀

✳标注流程要点

1. 先判断整张图意图，优先级 强 > 弱 > 无。

  1. 首先排除三大类不可渲染的【文字过多】【排版复杂的人工制图】【复杂的 app 截图】→ 标不可渲染，不需要判断 OCR 框。
  2. if 含有强意图：
    强 + 强 → 只要有 1 个强意图可渲染，整张图可渲染；如果有不可渲染的 OCR 框，需要标记。
    强 + 弱 或 强 + 无 → 只要有 1 个强意图可渲染，整张图可渲染；如果有不可渲染的 OCR 框，需要标记。
  3. if 含有弱意图：
    纯弱 → 分别判断 OCR 框是否可渲染，只要有 1 个框可渲染，图片标为可渲染；如有不可渲染的框需要标出。
    弱 + 无 → 分别判断 OCR 框是否可渲染，只要有 1 个框可渲染，图片标为可渲染；如有不可渲染的框需要标出。
  4. if 无意图 → 标不可渲染，不需要判断 OCR 框。

2. 实际标注中，第一遍先标意图，第二遍再标不可渲染的 OCR 框。第一遍把含有不可渲染的 OCR 框的图片标记出来。
